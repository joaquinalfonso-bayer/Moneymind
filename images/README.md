# Moneymind image slots

Replace each file below with your own image, keeping the SAME file name
(or update the src in index.html). Export at the listed size (2x retina)
for a sharp result. Images are cropped with object-fit: cover, anchored
to the top, so keep important content away from the bottom edge on
cropped cards.

Notes
- These are SCREEN images only: the phone frame, notch and 3D tilt are
  drawn in CSS. Keep the top ~60px clear for the notch.
- JPG or WebP also work: change the extension in index.html.
- If you prefer full phone mockup renders (frame included, transparent PNG),
  remove the surrounding .phone styling or ask for a mockup variant.
