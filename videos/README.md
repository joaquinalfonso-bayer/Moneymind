# Hero background video

Drop your file here as `hero-bg.mp4` (optionally also `hero-bg.webm`).

- Recommended: 1920 x 1080 (16:9), 8-20 s seamless loop, H.264 MP4, ideally under 6 MB
- No audio needed: it plays muted (browsers only autoplay muted video)
- It is cropped to fill the hero (object-fit: cover), centred. The headline sits
  on the left, so keep the key motion centre/right.
- Optional poster frame: add poster="images/hero-poster.jpg" to the <video> tag.
- Readability overlay: adjust or remove `.hero__overlay` in styles.css.
